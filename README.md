# Made Painting Service Plus — site

Landing page de madepaintingservice.com, publicada pela Netlify a partir deste repositório.

- `index.html` — a página (inglês, português e espanhol)
- `img/` — fotos das obras, já tratadas para a web
- `brand/` — o logo em vetor (SVG) e em PNG 2000 px

Cada envio para `main` publica o site automaticamente.
